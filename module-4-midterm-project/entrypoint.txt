This is the document explains the execution flow of the project
1. Initilise the virtual environment and install dependencies
    conda create --prefix ./my_env python=3.13 -y
    conda activate ./my_env
    pip install -r requirements.txt --upgrade
2. Run the redis docker container
    docker run -d --name genai-redis -p 6379:6379 redis/redis-stack-server:latest
3. Make sure the .env file having the required apikeys
4. Rund the loadcorpus.py to load the corpus to the vector store
5. Run the api_server.py to run the RAG pipeline
6. Run the frontend.py to run the frontend

###########################################################################################
This document also explain the overal code structure of the project in the following order,
###########################################################################################
1. config.py: This module consists of the config related code like,
    - config variables
    - config functions
2. vector_store.py: This module consists of the vector store related code like,
    - initilise the vector store
    - add documents to the vector store
    - retrieve documents from the vector store
3. load_corpus.py: This module consists of the load corpus related code like,
    - load corpus to the vector store
4. retrieval.py: This module consists of the retrieval related code like,
    - retrieve documents from the vector store
    - retrieve documents with scores from the vector store
5. router.py: This module consists of the router related code like,
    - build prompt for the response generation
    - verify context
6. llm_client.py: This module consists of the llm client related code like,
    - invoke the model
    - pass the model name and prompt
7. cache_store.py: This module consists of the cache store related code like,
    - initilise the cache store
    - add documents to the cache store
    - retrieve documents from the cache store
8. semantic_cache.py: This module consists of the semantic cache related code like,
    - initilise the semantic cache
    - retrieve documents from the semantic cache
    - retrieve documents with scores from the semantic cache
9. proximity_retrieval_cache.py: This module consists of the proximity retrieval cache related code like,
    - initilise the proximity retrieval cache
    - retrieve documents from the proximity retrieval cache
    - retrieve documents with scores from the proximity retrieval cache
10. guardrails.py: This module consists of the guardrails related code like,
    - validate the response
    - validate the context
11. post_process.py: This module consists of the post process related code like,
    - post process the response
12. observability.py: This module consists of the observability related code like,
    - start metrics server
    - start tracing server
13. pipeline.py: This module consists of the main pipeline related code like,
    - run the RAG pipeline
    - this module is the main entry point for the RAG pipeline
14. api_server.py: This module consists of the api server related code like,
    - start the api server
    - this module is the main entry point for the api server
15. frontend.py: This module consists of the frontend related code like,
    - start the frontend
    - this module is the main entry point for the frontend
###########################################################################################
